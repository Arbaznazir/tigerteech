# Tigerteeh Admin (Seller Panel)

Next.js dashboard on port **3001**.

```bash
cp .env.local.example .env.local   # or use existing .env.local
npm install
npm run dev
```

Login with the seeded admin from the Go API:

- `admin@tigerteehclothing.com` / `TigerteehAdmin1!`

Requires `backend` running on `:4000`.
